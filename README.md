## 🚀 Overview

Comfort Journey is a bespoke, ultra-fast custom web application built with modern **React 18 + Vite** for domestic (India) and international luxury tour packages. 

It completely replaces slow, bloated template builders with **100% custom-coded architecture**, 60fps micro-animations, multi-currency live conversions, an AI Dream Trip Planner, and an interactive live budget estimator.

---

## ✨ Key Features

1. **🎬 Cinematic Destination Hero:** Ambient visual crossfade across world-class destinations (Kashmir, Bali, Swiss Alps, Dubai) with live destination weather ticker.
2. **🤖 AI Dream Trip Planner:** 4-step smart generator crafting tailored day-by-day itineraries and instant price estimates.
3. **💱 Multi-Currency Global Engine:** Dynamic currency converter supporting **₹ INR, $ USD, € EUR, د.إ AED, £ GBP** across all cards and modals.
4. **🎛️ Interactive Trip Studio:** Custom 3–12 days slider, hotel tier selector (3★, 4★, 5★ Palace/Villas), transport picker (Sedan, SUV Crysta, Luxury Coach), and live price recalculator.
5. **🗺️ Interactive Day-Wise Itinerary Modal:** Step-by-step day breakdown with verified inclusions, hotel ratings, and 1-click WhatsApp booking.
6. **📱 Traveler Video Stories & Reels Wall:** TikTok/Reels style vertical video experiences and verified Google 5-star customer reviews.
7. **💬 WhatsApp Booking Concierge:** Instant pre-filled dynamic inquiry messages connected to `+91 8770403315`.
8. **⚡ 95–100 Google PageSpeed Performance:** Ultra-lightweight bundle loading in under 1 second worldwide.
